# SmallWebReader — Frontend Workspace Pack

This pack is for the frontend developer. Extract its contents into the root of your existing frontend project folder.

## Contents
- `AGENTS.md` — frontend-specific coding-agent instructions
- `docs/PROJECT_SPEC.md` — shared provisional project specification
- `docs/API_CONTRACT.md` — shared proposed API contract; requires team approval
- `docs/ARCHITECTURE.md` — shared provisional architecture
- `docs/TASKS.md` — shared work breakdown
- `docs/TEST_PLAN.md` — shared verification plan
- `docs/FRONTEND_PLAN.md` — frontend implementation plan template
- `docs/HANDOFF.md` — frontend handoff template

## Important
These are drafts, not a finalized project contract. Confirm them against the official hackathon problem statement and the team's final integrated report. In particular, do not implement the proposed API route until the backend and frontend owners agree on it.

## Suggested next step
Open the frontend project root in Antigravity, read `AGENTS.md`, then ask the agent to inspect the existing frontend and produce a concise plan before coding.
